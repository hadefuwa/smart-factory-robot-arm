Deploying to the Pi
===================

Make changes on the Windows machine, never edit files directly on the Pi.
The Pi has NO internet (eth0 = PLC network, wlan0 = hotspot), so `git pull` on
the Pi does not work. Files go over SCP. Use the IP; the hostname `rpi` does not
always resolve.

1. Commit and push from Windows (this repo lives in the DP0056 OneDrive folder):

    cd "C:\Users\HamedA\OneDrive - MATRIX TECHNOLOGY SOLUTIONS\Smart Factory 2 DP0056\Software\RaspberryPi Software"
    git status
    git add .
    git commit -m "message"
    git push origin main

2. Copy the changed file(s) to the Pi (usual method):

    scp app/backend/config.json pi@192.168.7.5:/home/pi/sf2/app/backend/
    scp app/frontend/robot-arm.html pi@192.168.7.5:/home/pi/sf2/app/frontend/
    scp -r app/robotarmv3-pi-service/ pi@192.168.7.5:/home/pi/sf2/app/robotarmv3-pi-service/

3. Restart what changed:

    ssh pi@192.168.7.5 "sudo systemctl restart smart-factory.service"                          (Flask backend + web UI)
    ssh pi@192.168.7.5 "sudo systemctl restart robotarmv3-pi.service"                          (Node arm bridge)
    ssh pi@192.168.7.5 "sudo systemctl restart smart-factory.service robotarmv3-pi.service"    (both)

   Frontend-only changes (html/js/css) need no restart, just refresh the browser.
   Restarting the arm bridge turns arm torque off via the safety interlock; re-enable
   it from the PLC/HMI (DB123.DBX40.0) afterwards.

Keeping the Pi's git history in sync (optional, when the Pi checkout is clean)
------------------------------------------------------------------------------
    PIHEAD=$(ssh pi@192.168.7.5 'cd ~/sf2 && git rev-parse HEAD')
    git bundle create $TEMP/sf2-update.bundle $PIHEAD..main
    scp $TEMP/sf2-update.bundle pi@192.168.7.5:~/sf2-update.bundle
    ssh pi@192.168.7.5 'cd ~/sf2 && git fetch ~/sf2-update.bundle main:refs/remotes/origin/main && git merge --ff-only origin/main'

Releases
--------
    git tag -a v5.0.2 -m "Release v5.0.2"; git push origin v5.0.2

Live status
-----------
    ssh pi@192.168.7.5 "sudo systemctl is-active smart-factory.service robotarmv3-pi.service vision.service"
    ssh pi@192.168.7.5 "curl -sk https://localhost:8080/api/robot-arm/status | python3 -m json.tool"
    ssh pi@192.168.7.5 "sudo journalctl -u smart-factory.service -u robotarmv3-pi.service -f"
